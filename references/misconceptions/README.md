# Subject misconception notes

Each file lists misconceptions students commonly hold in a subject. For each one it gives what the misconception looks like in student work, why students think it, and a quick teaching response. Skills read these when they write misconception notes, hinge-question distractors, answer-key commentary and reteach plans.

**Status: DRAFT, awaiting educator review.** These were compiled from published research and common teaching knowledge. Teachers and department colleagues are the best source of improvements: add what you see in real student work.

## Template for a new subject file

```
# <Subject> — common misconceptions

## <Topic>

### <Short name of the misconception>
- **Looks like:** an example of the student error
- **Why:** the reasoning behind it
- **Response:** a 1-2 minute teaching move (a counterexample, question, visual, or "find the mistake" task)
- **Hinge distractor:** an answer choice that reveals it
```
