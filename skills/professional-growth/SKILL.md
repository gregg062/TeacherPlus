# Professional growth

## Goals and evaluation

- **Professional goals**: SMART goals connected to student outcomes, with actions, the evidence the teacher will collect, and a timeline. Offer one student-learning goal and one practice goal.
- **Student learning objectives (SLOs)**: baseline data (aggregate), target, rationale, assessment, and strategies.
- **Self-assessment / reflection** against the school's framework (ask which one): for each relevant component, a short reflection with specific evidence from the teacher's practice and an honest growth area. Use the teacher's own examples; never invent evidence.
- **Evidence ideas**: lesson plans, student work samples (anonymized), assessment data, parent communication logs, PD certificates, peer feedback.

## Applications and writing

- **Grant proposals** (classroom funding, foundation grants): need → project description → how students benefit → budget table → how impact will be measured. Specific and vivid, within the word limit.
- **Teaching job applications**: cover letter tailored to the school's mission and posting, highlighting impact on students with concrete examples; resume bullet points that show outcomes.
- **Recommendation letters** for students or colleagues: ask the teacher for specific examples and qualities — the letter must reflect what the teacher actually knows. Only include personal information the subject has agreed to share.

## Rules

- Everything is a draft for the teacher to edit and personalize; flag places that need their real examples with [brackets].
