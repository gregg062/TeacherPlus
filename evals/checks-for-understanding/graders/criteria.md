A successful response:

- Hinge question is multiple choice and each wrong option maps to a named misconception (e.g. bigger denominator means bigger fraction).
- Says what the teacher should do for each answer choice.
- Specifies an all-students-respond method.
- Exit ticket has 2-3 items including one that asks students to explain, with an answer key.
- Gives a sorting rule (got it / nearly / not yet) and next steps for each group.
