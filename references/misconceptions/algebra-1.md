# Algebra 1 — common misconceptions

Status: DRAFT, awaiting educator review. Sources include Kieran (1981), Knuth et al. (2006), Booth et al. (2014) and the IES algebra practice guide (Star et al., 2015). Full citations are in `../research.md`, plus classroom experience.

## Equality and equations

### The equal sign means "the answer comes next"
- **Looks like:** 8 + 4 = __ + 5 answered 12; writing run-on chains like 3x = 12 = x = 4.
- **Why:** years of arithmetic where "=" is followed by a result.
- **Response:** use balance language ("both sides have the same value"); true/false tasks like 7 = 3 + 4 and 5 + 2 = 4 + 3; insist on one equation per line.
- **Hinge distractor:** 12 for 8 + 4 = __ + 5.

### Doing an operation to only one side, or one term
- **Looks like:** 2x + 6 = 14 → 2x = 14 + 6; or (2x + 6)/2 = x + 6.
- **Why:** treats "move it to the other side" as a trick rather than doing the same thing to both sides; divides only the first term.
- **Response:** annotate every step with the operation applied to *both whole sides*; balance model; check the solution by substitution every time.
- **Hinge distractor:** x = 10 for 2x + 6 = 14.

### Sign errors when "moving" terms
- **Looks like:** x − 5 = 12 → x = 7.
- **Why:** memorized "change sides, change sign" without meaning.
- **Response:** say "add 5 to both sides" rather than "move the 5"; check by substitution.

### Distributing to only the first term
- **Looks like:** 3(x + 4) = 3x + 4; −2(x − 5) = −2x − 10.
- **Why:** incomplete understanding of multiplication over a sum; the negative sign is not distributed.
- **Response:** area model (rectangle with sides 3 and x + 4); test with x = 1 to show the two expressions differ.
- **Hinge distractor:** 3x + 4.

### Combining unlike terms
- **Looks like:** 3x + 2 = 5x; 2x + 3y = 5xy; x + x = x².
- **Why:** "the 3 and 2 are both numbers so add them"; variables seen as labels ("3 apples + 2 bananas").
- **Response:** substitute values (x = 10) to test whether the expressions are equal; algebra tiles.

### Variables as labels or as a single unknown only
- **Looks like:** "x can only be one number"; in "6S = P", where S is the number of students and P the number of professors, writing it backwards.
- **Why:** letters read as abbreviations ("S = students") rather than quantities.
- **Response:** define variables as "the number of…"; test the equation with a numerical example.

## Inequalities

### Not reversing the inequality when multiplying or dividing by a negative
- **Looks like:** −2x < 6 → x < −3.
- **Why:** treats inequalities exactly like equations.
- **Response:** test a value: x = 0 satisfies −2(0) < 6 but not x < −3. Show on a number line that multiplying by −1 reflects the numbers.
- **Hinge distractor:** x < −3.

### Open vs. closed circles / solid vs. dashed boundary lines
- **Looks like:** closed circle for x > 2; solid line for y < 2x + 1.
- **Why:** doesn't connect "or equal to" to whether the boundary is included.
- **Response:** test the boundary point itself: is x = 2 a solution of x > 2?

### Shading the wrong half-plane
- **Looks like:** shading above for y < x + 1, or shading based on the symbol direction when the inequality is written as x + 1 > y.
- **Why:** "less than = below" rule applied without solving for y first, or applied to a non-standard form.
- **Response:** always use a test point (0, 0 if not on the line) and shade the side where it works.

## Linear functions and graphs

### Slope as run over rise, or sign errors in slope
- **Looks like:** slope of (1, 2) to (3, 8) given as 1/3 or −3.
- **Why:** order of subtraction inconsistent; formula memorized without meaning.
- **Response:** always sketch: "Is the line going up or down? So is the slope positive or negative?" Use rise and run arrows on the graph.

### Confusing slope and y-intercept in y = mx + b
- **Looks like:** graphing y = 3x + 2 starting at (0, 3) with slope 2.
- **Why:** positions memorized, not meaning.
- **Response:** table of values: what is y when x = 0? How much does y change when x goes up 1?

### Slope of a horizontal vs. vertical line
- **Looks like:** horizontal line has "no slope"; vertical has slope 0.
- **Why:** "no slope" and "zero slope" sound alike.
- **Response:** compute both with two points; "zero slope = flat road; undefined = wall".

### Graphing from standard form without rearranging
- **Looks like:** 2x + 3y = 6 graphed with slope 2 and intercept 6.
- **Why:** treats any linear equation as y = mx + b.
- **Response:** intercepts method (x = 0, y = 0) or solve for y first; check a point.

## Systems of equations

### A solution is a single number
- **Looks like:** finding x = 3 and stopping; reporting (y, x).
- **Why:** doesn't see that the solution is the point that works in both equations.
- **Response:** solution = ordered pair that makes *both* equations true; always finish by substituting into both.
- **Hinge distractor:** just "3", or (1, 3) when the answer is (3, 1).

### Substitution mistakes: forgetting parentheses, or substituting back into the same equation
- **Looks like:** substituting y = −x + 4 into 2x − y = 5 and writing 2x − x + 4 = 5 instead of 2x − (−x + 4) = 5, which gives 2x + x − 4 = 5.
- **Why:** not wrapping the substituted expression in parentheses.
- **Response:** "Replace y with ( )"; write the parentheses first, then fill them.

### Elimination: multiplying only one side or one term
- **Looks like:** multiplying 2x + y = 7 by 3 → 6x + y = 21.
- **Why:** same root as doing an operation to one term.
- **Response:** box the whole equation and multiply everything in the box.

### Misinterpreting 0 = 5 and 0 = 0
- **Looks like:** "x = 0 so the solution is (0, 5)", or "the answer is 0".
- **Why:** expects a number at the end.
- **Response:** connect to graphs: parallel lines never meet (no solution); the same line (infinitely many). Ask "Is 0 = 5 ever true?".

### Graphing solutions read imprecisely
- **Looks like:** reading (2.5, 3) as (2, 3).
- **Why:** sloppy graphs, non-integer intersections.
- **Response:** graphing gives an estimate; check algebraically by substitution.

## Word problems and modeling

### Keyword translation
- **Looks like:** "5 less than a number" → 5 − n; "there are 6 times as many students as teachers" → 6s = t.
- **Why:** word-by-word translation.
- **Response:** define variables, then test with a concrete number ("if there were 2 teachers, how many students?").

### Answering a different question than asked
- **Looks like:** solving for x but the question asks for the total cost.
- **Response:** underline the question; write a sentence answer with units.

## Exponents and polynomials (later Algebra 1)

### (a + b)² = a² + b²
- **Response:** area model; test with a = 1, b = 2.

### x⁰ = 0 or 2³ = 6
- **Response:** patterns: 2³ = 8, 2² = 4, 2¹ = 2, 2⁰ = ?

### −3² = 9
- **Why:** order of operations with negatives; ( −3)² vs −3².
- **Response:** say it aloud: "the opposite of three squared".
