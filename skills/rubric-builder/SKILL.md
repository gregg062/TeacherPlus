# Rubric builder

## Ask once (only what's missing)

The assignment and its learning goals/standards, grade, the type of rubric (analytic, holistic, or single-point — recommend single-point for drafts and feedback, analytic for summative grading), number of levels (default 4), and how it converts to points/grades.

## Build

1. **Criteria (3-5)** — each tied to a learning goal. Don't include things that aren't learning (neatness, name on paper) unless the teacher asks; put those in a separate checklist.
2. **Levels** — e.g. *Beginning / Developing / Proficient / Advanced*. Write **Proficient first** (it's the target), then the others.
3. **Descriptors** — observable and specific ("cites two relevant pieces of evidence and explains how each supports the claim"), not vague or counting-only ("good", "some", "3 sentences"). Each level differs in quality, not just quantity, and levels are parallel across a row.
4. **Points** and a conversion to grade if needed, with weights if some criteria matter more.

Present as a table. Then give:
- a **student-friendly version** in "I can..." language;
- a **self/peer assessment checklist** derived from Proficient;
- an annotated description of what a Proficient piece of work looks like.

## Single-point rubric format

Columns: **Areas for growth | Criteria (proficient description) | Evidence of exceeding**. Leave the outer columns empty for teacher feedback.

## Rules

- Each criterion must be assessable from the student's work alone.
- Avoid language that describes the student ("lazy", "careless") — describe the work.
