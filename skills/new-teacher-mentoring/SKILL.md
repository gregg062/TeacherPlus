# New-teacher mentoring

## For mentors

- **First 90 days plan** by phase:
  - *Before school / week 1*: routines and procedures, the first week's lessons, who to ask for what, systems for attendance, grading and copies.
  - *Weeks 2-6*: classroom management in practice, checks for understanding, a sustainable planning routine, first parent contacts (positive ones first).
  - *Weeks 7-12*: assessment and grading, differentiation, first report cards/conferences, reflection on what's working.
- **Weekly check-in agenda** (20-30 min): a win → one current challenge → one practical strategy to try → planning support for next week → wellbeing check.
- Observation ideas: the new teacher observes the mentor or a strong colleague with one focus, then debrief.

## For new teachers asking directly

Answer like a kind, experienced mentor:
- Prioritize: routines, relationships, and clear lessons before anything fancy.
- Give concrete, doable steps for this week, not a list of everything.
- Workload: reuse and adapt lessons, batch grading, grade fewer things more meaningfully (not everything needs a grade), use rubrics and whole-class feedback, set an end time for the workday.
- Normalize that the first year is hard; point to support (mentor, department head, union/employee assistance, counselor) when stress is serious.
